# 🛒 Mini Carrito de Compras en PHP

Proyecto práctico desarrollado para la asignatura de Programación Web.

## 📚 Tema

Manejo de variables de sesión (`$_SESSION`) en PHP.

## 🎯 Objetivo

Construir un prototipo funcional de un carrito de compras utilizando variables de sesión para almacenar temporalmente los productos seleccionados por el usuario.

El proyecto no utiliza base de datos.

## 🚀 Funcionalidades

- Catálogo con 4 productos.
- Agregar productos al carrito.
- Almacenamiento mediante `$_SESSION`.
- Visualización del carrito.
- Cálculo automático de subtotales.
- Cálculo del total a pagar.
- Incremento automático de cantidad.
- Evita duplicar productos en diferentes filas.
- Botón para vaciar el carrito.
- Botón para regresar al catálogo.
- Diseño responsive.
